# speech_diarization: 話者分離(誰がいつ話したか)

まだ着手していない(計画のメモ)。

## 目的

話者のラベルがない音声(テレビ・動画など)に、自動で話者のラベルを付けられるようにする。
付けたラベルを、多話者の TTS の学習データ作りに使う(例: [tts/indextts_bases/](../tts/indextts_bases/) のフェーズ B の exp0104 で、
話者の情報がない ReazonSpeech を足すとき)。

## TTS の学習で話者のラベルが必要なところ

tts/indextts_bases の exp0101 の構成で、話者のラベルを使っているところ:

- T2S・S2M に入れる話者ベクトル(CAM++)は、正解の発話そのものではなく「同じ話者の別の発話」から取る
  (その発話の中身・抑揚が話者ベクトルから漏れないように)。同じ話者の発話をまとめるのにラベルが要る
- 学習に使う話者・使わない話者への分け方と、話者類似度の評価

S2M のプロンプト(参照音声の Mel)は同じ発話の先頭の一部なので、ラベルは要らない。

このため、学習データ作りに必要なのは「1 つの音声ファイル(番組・動画)の中で、どの区間が同じ人か」まで。
ファイルをまたいで同じ人かどうか(同じ人が別の番組に出ているか)までは要らない。ただし、話者を分けて評価するときは、
ファイルをまたいで同じ人が学習・評価の両方に入らないかに注意が要る。

## 調べたいこと(案)

- 手法: 既存の手法(pyannote など)と、自作の構成(話者ベクトル + クラスタリング、end-to-end のモデル)の比較
- 評価: 話者のラベルがあるデータ(JVS など)を混ぜて作った音声、公開の評価セットでの DER(誤りの割合)
- TTS への影響: 自動のラベルで学習した TTS と、正しいラベルで学習した TTS の比較(話者類似度など)
