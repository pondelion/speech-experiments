# exp0102: 話者の情報の入れ方

- **基準**: exp0101 の基礎の構成(`scratch`: スクラッチから学習したもの。exp0101 で finetune との差は小さかったが、試聴で少し良く聞こえたため)
- **変えるもの**: 話者の情報を「どこに」「何を」入れるか、声の高さ(F0)の正規化の仕方。どの比較も、基準から 1 つの条件だけを変える

## 目的

exp0101 で、学習に使わない話者の大まかな特徴(性別など)では読めるようになったが、参照音声と同じ人物の声とは程遠く感じることが多い
(CAM++ の話者類似度 0.792、本物の録音どうしは 0.83)。また、声の高さの平均が本物の録音と約 2 半音(195 セント)ずれている。
この exp では:

1. 今の構成で、話者の情報のどの入れ方が声の似かたに効いているかを切り分ける(どこに入れるか)
2. 声の似かた・声の高さを良くする入れ方を試す(何を入れるか、F0 の正規化の仕方)

## exp0101 で分かっていること(この exp の出発点)

| 項目 | 今の基準(exp0101 の scratch) |
|---|---|
| T2S に入る話者の情報 | CAM++ の話者ベクトル 1 本(192 次元、発話全体を時間方向にまとめたもの)を、テキストの encoder の入力と、時刻の埋め込みに足す |
| S2M に入る話者の情報 | (1) 参照音声の Mel の系列(プロンプト)、(2) CAM++ の話者ベクトル(時刻の埋め込みに足す)。参照音声のトークン・F0 も前につなげる |
| F0 の正規化 | T2S の F0 の補助の損失の正解、S2M の F0 の条件とも、JSUT(フェーズ A)の log F0 の平均・標準偏差で正規化(全話者で同じ値) |
| 結果(学習に使わない 10 人) | CAM++ の話者類似度 0.792、WavLM 0.953、声の高さの平均の差 195 セント、実用文の CER 5.9% |

声の高さがずれる理由として考えられること(まだ確かめていない): F0 を全話者で同じ値で正規化しているので、T2S は「話者ごとの声の高さ」を
話者ベクトルから決める必要がある。話者ベクトルは発話全体をならした 1 本なので、声の高さの情報を十分に持っていない可能性がある。

## 比べるもの

どれも基準(B0)から 1 つの条件だけを変える。学習し直すのは、変えた条件に関わる部品だけ(もう一方の部品は基準のものをそのまま使う)。
学習し直す部品も、基準と同じくスクラッチから学習する。データ・学習の設定(学習率・step 数・バッチ・乱数の種)・生成の設定・評価は、exp0101 と同じ。

### 1. どこに入れるか(今の構成から 1 つずつ外して、効き方を切り分ける)

| 条件 | 基準からの違い(1 つだけ) | 学習し直す部品 |
|---|---|---|
| B0(基準) | - | - |
| `no_t2s_spk` | T2S の話者ベクトルを外す(T2S は話者に関係なく同じトークンを作る) | T2S |
| `no_s2m_prompt` | S2M の参照音声の Mel(プロンプト)を外す(参照音声のトークン・F0 を前につなげることもしない) | S2M |
| `no_s2m_style` | S2M の話者ベクトルを外す(プロンプトだけで声を決める) | S2M |

### 2. 何を入れるか

| 条件 | 基準からの違い(1 つだけ) | 学習し直す部品 |
|---|---|---|
| `t2s_ref_encoder` | T2S の話者の条件を、CAM++ の 1 本から、参照音声の Mel の系列を読む encoder(IndexTTS2 の T2S と同じ Conformer + Perceiver の形。32 本のベクトルにまとめる。大きさは T2S に合わせる)に替える。時間ごとの声の特徴・話し方も T2S に入るようにする | T2S |

`t2s_ref_encoder` の実装(`exp0101/common/t2s_ref.py`):

- encoder: ネットワークの定義は公式のリポジトリ(`vendor/index-tts`)の Conformer・Perceiver をそのまま使う。大きさも公式の設定と同じ
  (Conformer: 512 次元・6 層・FFN 2,048・8 ヘッド・時間方向を 1/2 にする畳み込み。Perceiver: 32 本・FFN 倍率 2)。512 次元は T2S の次元と同じ。
  入力は公式の w2v-BERT の特徴の代わりに参照の発話の Mel(S2M と同じ正規化、先頭の 1,000 フレームまで)。スクラッチから学習する。
  encoder の分だけ T2S のパラメータが増える(54M → 94M)
- 参照の発話: 基準の CAM++ の話者ベクトルと同じ発話(学習では同じ話者の別の発話、評価では参照音声)
- 入れる場所: 基準と同じ 2 か所。32 本の系列になるので、テキストの encoder にはテキストのトークンの前につなげ(出力ではその 32 本の位置を捨てる)、
  時刻の埋め込みには 32 本の平均を Linear(重みは 0 から)で射影して足す
- 学習の設定は基準と同じ。メモリを抑えるため Conformer の各層で勾配 checkpointing を使う(計算の結果は同じ。学習中の GPU のメモリは約 9GiB、
  使わないと約 23GiB)

### 3. 声の高さ(F0)の正規化

| 条件 | 基準からの違い(1 つだけ) | 学習し直す部品 |
|---|---|---|
| `f0_per_speaker` | F0 の正規化の平均を、全話者で同じ JSUT の値から、「話者ベクトルを取った参照の発話」の有声の log2 F0 の平均に替える(学習ではその発話、推論では参照音声。標準偏差は JSUT の値のまま。推論では参照音声 1 発話から求めるので、1 発話では不安定な標準偏差は話者ごとにしない)。T2S の F0 の補助の損失の正解と、S2M の F0 の条件(参照音声の区間も含む)の両方で同じ正規化を使う(正規化の仕方という 1 つの条件を、F0 を使う全ての場所でそろえて替える) | T2S・S2M |

## 評価

exp0101 と同じ(`synth.py`・`metrics.py` を使う)。主に見る値も同じ:

- 話者類似度(WavLM・CAM++)、声の高さの平均の差、本物の録音と比べる F0 の指標: テスト文 25 文(学習に使わない 10 人・使った 10 人)
- CER・UTMOS: 実用文 55 文

CAM++ はモデルの部品にも使っているので、CAM++ の話者類似度は、CAM++ の話者ベクトルを入れている条件で高めに出る可能性がある
(部品と同じモデルで測っているため)。条件どうしの比較では、部品に使っていない WavLM の値を主に見る。

## 決めたこと

- 基準は exp0101 の scratch にする
- 学習の乱数によるばらつき(学習し直したときの差)は測らない。差が小さい比較は、そのことを踏まえて読む
- 順番: 1(切り分け、学習 3 回)→ 3(F0 の正規化、学習 2 回)→ 2(T2S の encoder、学習 1 回)。1 で、どの部品が声の似かたを
  決めているかが分かると、2・3 のどちらを優先するかを判断できる

## 実行方法

exp0101 のスクリプトに、条件を切り替えるオプションを足して使う(指定しなければ exp0101 と同じ動き。条件は checkpoint の `options` に保存し、
`synth.py` はそれを読んで同じ設定で合成する)。データ(`exp0101/runs/` の Mel・トークン・F0・話者ベクトル)とボコーダ(`vocos_multi`)は
exp0101 のものを使う。基準(B0)の結果は exp0101 の `results/metrics_scratch.json`。

```
cd ../exp0101
python train_t2s.py --init scratch --no_spk --runs_dir ../exp0102/runs --name t2s_no_spk
python train_s2m.py --init scratch --no_prompt --runs_dir ../exp0102/runs --name s2m_no_prompt
python train_s2m.py --init scratch --no_style --runs_dir ../exp0102/runs --name s2m_no_style
python train_t2s.py --init scratch --f0_norm ref_mean --runs_dir ../exp0102/runs --name t2s_f0_ref_mean
python train_s2m.py --init scratch --f0_norm ref_mean --runs_dir ../exp0102/runs --name s2m_f0_ref_mean
python train_t2s.py --init scratch --ref_encoder --runs_dir ../exp0102/runs --name t2s_ref_encoder
# 評価(学習し直さない部品は exp0101 の scratch のもの)
python synth.py --cond spk --t2s ../../exp0102/runs/t2s_no_spk --s2m s2m_scratch --vocoder vocos_multi --out_root ../exp0102/runs --name no_t2s_spk
python metrics.py --name no_t2s_spk --exp_dir ../exp0102
# 試聴用の音声(行・文は exp0101 と同じ。ずんだもんの行は条件ごとに --ref_wav で合成する。B0 の列は exp0101 の MP3 を写す)
python synth.py --cond spk --t2s ../../exp0102/runs/t2s_no_spk --s2m s2m_scratch --vocoder vocos_multi --seeds 1 \
    --ref_wav runs/zundamon/ref.wav --ref_name zundamon --out_root ../exp0102/runs --name zundamon_no_t2s_spk
python ../exp0102/make_samples.py
```

## 結果

値は乱数の種 0・1・2(合成の乱数)の平均。± は合成の乱数によるばらつきで、学習し直したときのばらつきは測っていない(「決めたこと」のとおり)。
基準(B0)は exp0101 の `results/metrics_scratch.json`。話者類似度は参照音声との cosine 類似度(テスト文)。本物の録音どうし(同じ話者の別の発話)は WavLM 0.963、CAM++ 0.819。

### 結果 1(比べるもの 1): `no_t2s_spk`: T2S の話者ベクトルを外す

| 指標 | 学習に使わない 10 人: B0 | `no_t2s_spk` | 学習に使った 10 人: B0 | `no_t2s_spk` |
|---|---|---|---|---|
| 話者類似度(WavLM) | 0.953 | 0.894 ± 0.002 | 0.963 | 0.918 ± 0.002 |
| 話者類似度(CAM++、参考) | 0.792 | 0.682 ± 0.002 | 0.849 | 0.739 ± 0.001 |
| 声の高さの平均の差(セント) | 195 | 598 ± 5 | 125 | 618 ± 6 |
| GPE(本物の録音と比べた F0 の大きな誤りの割合) | 0.284 | 0.663 ± 0.008 | 0.181 | 0.683 ± 0.002 |
| F0 の相関 | 0.968 | 0.966 | 0.976 | 0.968 |
| 長さの比(合成 / 本物) | 0.946 | 0.873 | 0.987 | 0.882 |
| CER(テスト文) | 5.3% | 6.3% | 5.0% | 6.4% |
| CER(実用文) | 5.9% | 6.8% | 6.2% | 7.4% |
| UTMOS(実用文) | 3.29 | 3.31 | 3.12 | 3.18 |

T2S の学習: 検証 loss が一番小さいのは 9,000 step(4.861。B0 は 5,000 step で 4.018)。検証の F0 の誤差(f0_mse)は 0.580(B0 は 0.239)。

- T2S から話者ベクトルを外すと、声の高さの平均の差が約 3〜5 倍(約 600 セント = 半オクターブ)になり、話者類似度も WavLM で約 0.05 下がった。
  S2M は B0 と同じもの(参照音声の Mel・話者ベクトルは入っている)なので、声の高さは S2M のプロンプトではなく、T2S が作る F0 でほぼ決まっている
- F0 の相関(抑揚の形)はほとんど変わらない。話者ベクトルが T2S で効いているのは、主に声の高さの水準と話す速さ(長さの比が 0.95 → 0.87。JVS は JSUT よりゆっくり読む)
- 学習に使った話者でも同じくらい悪くなるので、T2S の話者ベクトルは「学習に使わない話者への一般化」だけでなく、話者ごとの声の高さ・速さを決めるのに使われている

### 結果 2(比べるもの 1): `no_s2m_prompt`・`no_s2m_style`: S2M の参照音声の Mel(プロンプト)・話者ベクトルを外す

| 指標 | 学習に使わない 10 人: B0 | `no_s2m_prompt` | `no_s2m_style` | 学習に使った 10 人: B0 | `no_s2m_prompt` | `no_s2m_style` |
|---|---|---|---|---|---|---|
| 話者類似度(WavLM) | 0.953 | 0.941 ± 0.001 | 0.951 ± 0.001 | 0.963 | 0.960 | 0.961 |
| 話者類似度(CAM++、参考) | 0.792 | 0.701 ± 0.002 | 0.757 ± 0.002 | 0.849 | 0.818 | 0.819 |
| 声の高さの平均の差(セント) | 195 | 190 | 190 | 125 | 125 | 122 |
| GPE | 0.284 | 0.284 | 0.284 | 0.181 | 0.173 | 0.182 |
| CER(実用文) | 5.9% | 6.0% | 6.2% | 6.2% | 5.8% | 6.4% |
| UTMOS(実用文) | 3.29 | 3.34 | 3.28 | 3.12 | 3.13 | 3.16 |

S2M の検証 loss の一番小さい値: B0 0.2682、`no_s2m_prompt` 0.2703、`no_s2m_style` 0.2688(どれも 48,000〜50,000 step)。

- プロンプトを外すと、学習に使わない話者の話者類似度が下がる(WavLM 0.953 → 0.941、CAM++ 0.792 → 0.701)。学習に使った話者では下がり方が小さい(WavLM 0.963 → 0.960)。
  プロンプトは主に、学習に使わない話者の声の質を S2M に伝えている。声の高さは変わらない(1 の結果と合わせて、声の高さは T2S の F0 で決まる)
- 話者ベクトルを外しても、WavLM の話者類似度はほとんど変わらない(0.953 → 0.951)。CAM++ では 0.035 下がるが、CAM++ は話者ベクトルと同じモデルなので
  高めに出やすい(「評価」のとおり)。プロンプトがあれば、S2M の話者ベクトルの役割は小さい

### 結果 3(比べるもの 3): `f0_per_speaker`: F0 の正規化の平均を参照の発話の値にする

| 指標 | 学習に使わない 10 人: B0 | `f0_per_speaker` | 学習に使った 10 人: B0 | `f0_per_speaker` |
|---|---|---|---|---|
| 話者類似度(WavLM) | 0.953 | 0.954 ± 0.001 | 0.963 | 0.963 ± 0.001 |
| 話者類似度(CAM++、参考) | 0.792 | 0.792 ± 0.001 | 0.849 | 0.849 ± 0.001 |
| 声の高さの平均の差(セント) | 195 | 148 ± 2 | 125 | 140 ± 3 |
| GPE | 0.284 | 0.224 | 0.181 | 0.211 |
| F0 の誤差(RMSE、セント) | 156 | 154 | 147 | 159 |
| F0 の相関 | 0.968 | 0.969 | 0.976 | 0.973 |
| 長さの比(合成 / 本物) | 0.946 | 0.905 | 0.987 | 0.961 |
| CER(実用文) | 5.9% | 5.6% | 6.2% | 6.0% |
| UTMOS(実用文) | 3.29 | 3.31 | 3.12 | 3.06 |

T2S の検証 loss の一番小さい値: 4.068(5,500 step。B0 は 4.018。F0 の正解の正規化が違うので、F0 の損失を含む値はそのままは比べられない)。
S2M は 0.2696(B0 0.2682)。

- 学習に使わない話者では、声の高さの差が 195 → 148 セント、GPE が 0.284 → 0.224 に良くなった
- 学習に使った話者では逆に悪くなった(声の高さの差 125 → 140 セント、GPE 0.181 → 0.211、F0 の誤差 147 → 159 セント)。
  基準では学習に使った話者の声の高さを話者ベクトルから覚えられていたが、1 発話の平均で正規化すると、その発話の高さのぶれ(文による高さの違い)が
  正規化に入るためと考えられる(まだ確かめていない)
- 話者類似度は変わらない。長さの比が両方の話者で短くなった(0.946 → 0.905、0.987 → 0.961)。F0 の正規化だけを変えたので、
  学習し直したことによるばらつきの可能性もある(学習し直したときのばらつきは測っていない)

### ここまでのまとめ

| 話者の情報 | 効き方(学習に使わない話者) |
|---|---|
| T2S の話者ベクトル | 声の高さの水準と話す速さを決める。外すと声の高さが約 600 セントずれ、話者類似度も大きく下がる(WavLM 0.953 → 0.894) |
| S2M のプロンプト | 声の質を伝える。外すと話者類似度が下がる(0.953 → 0.941)。声の高さは変わらない |
| S2M の話者ベクトル | プロンプトがあれば、ほとんど効いていない(0.953 → 0.951) |
| F0 の正規化(参照の発話の平均) | 学習に使わない話者の声の高さのずれを減らす(195 → 148 セント)が、学習に使った話者では悪くなる(125 → 140) |
| T2S の話者の条件を参照音声の encoder に替える | 結果 4 のとおり |

### 結果 4(比べるもの 2): `t2s_ref_encoder`: T2S の話者の条件を、参照音声の Mel を読む encoder に替える

| 指標 | 学習に使わない 10 人: B0 | `t2s_ref_encoder` | 学習に使った 10 人: B0 | `t2s_ref_encoder` |
|---|---|---|---|---|
| 話者類似度(WavLM) | 0.953 | 0.954 ± 0.000 | 0.963 | 0.963 ± 0.000 |
| 話者類似度(CAM++、参考) | 0.792 | 0.789 ± 0.001 | 0.849 | 0.843 ± 0.001 |
| 声の高さの平均の差(セント) | 195 | 156 ± 2 | 125 | 114 ± 2 |
| GPE | 0.284 | 0.246 | 0.181 | 0.192 |
| F0 の誤差(RMSE、セント) | 156 | 153 | 147 | 151 |
| F0 の相関 | 0.968 | 0.970 | 0.976 | 0.975 |
| 長さの比(合成 / 本物) | 0.946 | 0.949 | 0.987 | 0.954 |
| CER(テスト文) | 5.3% | 5.8% | 5.0% | 5.8% |
| CER(実用文) | 5.9% | 6.8% | 6.2% | 7.0% |
| UTMOS(実用文) | 3.29 | 3.33 | 3.12 | 3.11 |

T2S の検証 loss の一番小さい値: 4.087(5,500 step。B0 は 5,000 step で 4.018)。学習は 4,803 秒(B0 の約 1.9 倍)。
GPU のメモリの予約は最大 15.6GiB(検証のとき。学習の最初の 20 step は 9.1GiB)。

- 学習に使わない話者で声の高さの差が 195 → 156 セント、GPE が 0.284 → 0.246 に良くなった。学習に使った話者でも声の高さの差は 125 → 114 セント。
  `f0_per_speaker`(学習に使わない話者 148 セント、学習に使った話者 140 セント)と違い、学習に使った話者でも悪くならない
- 話者類似度(WavLM)は変わらない(0.953 → 0.954)
- CER が上がった(実用文で 5.9% → 6.8%、テスト文で 5.3% → 5.8%)。学習に使った話者では長さの比も 0.987 → 0.954 に短くなった
- 学習し直したときのばらつきは測っていないので、声の高さ・CER の差がどこまでこの条件の効果かは分からない(差の大きさは、`f0_per_speaker` の長さの比の変化と同じくらい)

### 全体のまとめ

- 声の似かた(WavLM)を決めているのは、T2S の話者の条件(外すと 0.953 → 0.894)と S2M のプロンプト(外すと 0.941)。S2M の話者ベクトルはほとんど効いていない
- 声の高さは T2S の F0 で決まる。声の高さのずれ(195 セント)は、F0 の正規化を参照の発話の平均にする(148)か、T2S の話者の条件を参照音声の encoder にする(156)と減る。
  学習に使った話者でも悪くならないのは encoder の方(125 → 114。正規化の方は 125 → 140)
- どの条件でも、学習に使わない話者の WavLM の話者類似度は B0(0.953)を上回らなかった(一番高い値で 0.954)。本物の録音どうしは 0.963
